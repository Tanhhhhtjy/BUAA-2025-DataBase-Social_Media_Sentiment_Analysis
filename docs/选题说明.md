# 选题说明

社交媒体舆情分析系统（数据存储与处理核心）

## 三、作业内容说明

本系统旨在设计并实现一个专注于社交媒体数据存储与舆情分析的后端核心系统。通过对模拟生成的社交媒体数据（如用户发布的帖子、评论等）进行高效管理，并运用数据库技术实现情感分析、热点话题追踪与舆情监控等功能。

### 3.1 包含的主要实体名称

1. **用户 (Users)**
2. **帖子/文章 (Posts)**
3. **评论 (Comments)**
4. **话题标签 (Hashtags)**
5. **帖子-标签关联 (Post_Hashtags)**
6. **关键词 (Keywords)**
7. **情感倾向 (Sentiments)**
8. **帖子情感记录 (Post_Sentiments)**

### 3.2 包含的主要联系名称

- **Users 与 Posts** 之间的 **发布** 联系 (1:N)
- **Users 与 Comments** 之间的 **发表** 联系 (1:N)
- **Posts 与 Comments** 之间的 **拥有** 联系 (1:N)
- **Posts 与 Hashtags** 之间的 **标记** 联系 (M:N)，通过 Post_Hashtags 实现
- **Posts 与 Sentiments** 之间的 **具有** 联系 (M:N)，通过 Post_Sentiments 实现

---

## 四、小组同学分工

### 4.1 同学A：子任务1 - 系统功能设计与部分数据库操作实现

**主要职责**：

1. 需求分析
2. 系统功能设计（绘制数据流图、定义功能模块）
3. 实现复杂查询功能（热点话题看板、舆情趋势分析、情感分布分析、关键词预警查询）
4. 撰写系统设计报告中的【需求分析】和【系统功能设计】部分

### 4.2 同学B：子任务2 - 系统数据库设计与部分数据库操作实现

**主要职责**：

1. 数据库概念设计（绘制E-R图）
2. 数据库逻辑设计（设计关系模式，规范化至3NF）
3. 数据库物理设计（设计索引）
4. 实现数据操作功能（插入、更新、删除）、存储过程（情感分析、日报生成）及触发器（话题提取、级联删除）
5. 撰写系统设计报告中的【数据库概念/逻辑/物理设计】部分
