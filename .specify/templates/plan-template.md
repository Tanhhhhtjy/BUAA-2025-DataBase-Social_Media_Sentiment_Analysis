## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

**代码质量原则检查**:
- [ ] 所有 SQL 查询是否手写而非使用 ORM 自动生成
- [ ] 后端是否采用 Controller → Service → Mapper 分层架构
- [ ] 前端是否使用 Vue 3 组合式 API

**数据库设计原则检查**:
- [ ] 数据库设计是否满足 3NF 规范化
- [ ] 所有表是否定义主键和必要的外键约束
- [ ] 高频查询字段是否已建立索引

**安全性原则检查**:
- [ ] 用户认证是否使用 JWT 并设置合理过期时间
- [ ] SQL 操作是否使用参数绑定防止注入
- [ ] 用户密码是否哈希存储

**性能原则检查**:
- [ ] 分页查询是否使用 LIMIT/OFFSET 而非内存分页
- [ ] 大模型调用是否设计为异步任务

**测试原则检查**:
- [ ] 核心业务逻辑是否有单元测试覆盖
- [ ] 复杂 SQL 查询是否有独立测试用例

如有任何检查项未通过，必须在实施前提供充分的理由和风险评估。
